# Quest Pressures and Consequences

A pressure is an active world condition: shortage, ecological imbalance, unsafe travel, labor gap,
disputed authority, interrupted production, or failing infrastructure. It names cause, severity,
stakeholders, competing interests, valid grammars, escalation, resolution, recurrence, and scope.
No credible pressure means no generated quest.

A consequence is a declared result, not an implied reward line. It names target, effect type, scope,
duration, persistence, reversibility, reset, and conflict behavior. Safe generated effects are local,
temporary, personal, party, instance, settlement, zone, or regional. Locked records and unresolved
global mysteries are never mutated or objectively resolved by generated content.

The Greenhold loop is: low cistern → ledger discovery → compatible sluice repair → flowing local
state → changed civic evidence, while the origin of the old machinery remains unresolved.
