# Aethryn Combat Mockups

All transcripts are original and illustrative. They use the live continuous-tick model as the
presentation assumption.

## One-on-one

```
COMBAT — Vermin
Target: Vermin | Beat: 3
YOU > Strike Vermin for 8 physical damage. [Vermin 12/20 HP]
FOE > Vermin claws you for 2. [HP 30/32]
STATUS: HP 30/32 | MP 7/7 | Vermin 12/20
NEXT: attack Vermin | use <ability> | flee
```
